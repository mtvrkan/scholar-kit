# APA 7th Edition — Citation Styles

## In-Text Citations

| Context | Format | Example |
|---------|--------|---------|
| Parenthetical, single | (Author Year) | Smith (2023) found that… |
| Parenthetical, multiple | (Author Year; Author Year) | Some evidence (Smith 2023; Jones 2022) suggests… |
| With page number | (Author Year, p. #) | A key finding (Smith 2023, p. 45) is… |
| Multiple pages | (Author Year, pp. #–#) | The study (Smith 2023, pp. 45–47) showed… |
| Multiple authors (2) | (Smith & Jones 2023) | Smith and Jones (2023) noted… |
| Multiple authors (3–20) first mention | (Smith et al. 2023) | Smith et al. (2023) reported… |
| Same author, multiple years | (Smith 2020, 2023) | Evidence (Smith 2020, 2023) shows… |
| Same author, same year | (Smith 2023a, 2023b) | Two articles (Smith 2023a, 2023b) conflict… |
| No author, organization | (National Institute…, 2023) | A report (U.S. Department of Education, 2023)… |
| Personal communication | (J. Smith, personal communication, January 15, 2023) | According to a researcher (J. Smith, personal communication, January 15, 2023)… |

## Reference List Formats (20+ Source Types)

### Journal Article (online with DOI)
```
Smith, J., & Jones, K. (2023). Title of the article in title case. Journal Title in Title Case, 45(2), 234–251. https://doi.org/10.1234/example
```

### Journal Article (online, no DOI)
```
Brown, L. (2022). Article title in title case. Journal Name, 18(3), 445–462. https://www.example.com/article-url
```

### Journal Article (print only)
```
Davis, R. M., & Wilson, H. (2021). Examining the phenomenon. Research Quarterly, 52(1), 78–92.
```

### Book
```
Smith, K. A. (2020). Title of the book in title case (3rd ed.). Publisher Name. https://doi.org/10.1234/book
```

### Book Chapter
```
Jones, M. R. (2019). Chapter title in title case. In L. Davis (Ed.), Edited book title in title case (pp. 45–67). Academic Press.
```

### Conference Proceeding
```
Williams, P. J. (2023). Paper title in title case. In Proceedings of the 2023 International Conference on Computing (pp. 234–241). IEEE. https://doi.org/10.1234/conf
```

### Thesis (Doctoral)
```
Johnson, R. A. (2022). Title of dissertation [Doctoral dissertation, University Name]. ProQuest Dissertations and Theses Database.
```

### Thesis (Master's)
```
Lee, S. (2021). Title of the thesis [Master's thesis, University Name]. University Repository.
```

### Dataset
```
National Center for Biotechnology Information. (2023). Gene database: Release 233.0 [Data set]. Zenodo. https://doi.org/10.5281/zenodo.example
```

### Software/Code
```
Developers, X. (2023). TensorFlow: An open-source machine learning library (Version 2.12.0) [Software]. https://www.tensorflow.org
```

### Preprint (arXiv)
```
Taylor, N., & Kumar, A. (2023). Attention mechanisms revisited [Preprint]. arXiv. https://arxiv.org/abs/2301.12345
```

### Webpage
```
World Health Organization. (2023). COVID-19 guidelines. Retrieved January 15, 2024, from https://www.who.int/emergencies/diseases/novel-coronavirus-2019/
```

### Newspaper Article
```
reporter, P. (2023, March 15). Breaking news headline. The New York Times, A1.
```

### Report (Government/Organization)
```
U.S. Department of Education. (2023). National education trends report. Government Publishing Office.
```

### Standard/Technical Document
```
International Organization for Standardization. (2020). ISO/IEC 27001:2022 information security management systems (5th ed.). ISO.
```

### Translated Work (emphasize translation)
```
Kühn, T. S. (2020). The structure of scientific revolutions (K. Fidan, Trans.; 3rd ed.). Alpha Publishing House. (Original work published 1962)
```

### Institutional Author
```
Türkiye İstatistik Kurumu [Turkish Statistical Institute]. (2023). National income report 2022. TÜİK Publications.
```

### Work with No Individual Author or Date
```
Turkish Academy of Sciences. (n.d.). Turkish language terminology guide. Retrieved from https://tdk.gov.tr/
```

### Multiple Authors (1, 2, 3–20, 21+)
```
# One author
Smith, J. (2023).…

# Two authors
Smith, J., & Jones, K. (2023).…

# Three to twenty authors (list all)
Smith, J., Jones, K., Brown, L., Davis, R., Wilson, H., Taylor, N., Kumar, A., Singh, B., & Patel, C. (2023).…

# Twenty-one or more authors (list first 19, ellipsis, last author)
Smith, J., Jones, K., Brown, L., …, & Zulu, Z. (2023).…
```

### Same Author, Same Year (a, b, c)
```
Smith, J. (2023a). First article. Journal A, 10(1), 1–10.

Smith, J. (2023b). Second article. Journal B, 10(2), 20–30.

Smith, J. (2023c). Third article. Journal C, 10(3), 40–50.
```

### Secondary Citation (citing a source cited in another)
```
Aristotle (as cited in Jones, 2023) argued that…
```
Reference list includes only the secondary source (Jones, 2023), not Aristotle.

## Turkish-Specific Examples

### Turkish Journal Article
```
Kaya, M., & Şimşek, G. (2023). Görüntü sınıflandırmada derin evrişimsel ağların performansı [Performance of deep convolutional networks in image classification]. Mühendislik Bilimleri ve Tasarım Dergisi, 11(2), 245–258. https://doi.org/10.21923/jesd.example
```

### Turkish Thesis (YÖK Thesis Center)
```
Özdemir, A. (2021). Derin öğrenme kullanarak Türkçe metin sınıflandırması [Turkish text classification using deep learning] [Doctoral dissertation, Boğaziçi University]. YÖK National Thesis Center. https://tez.yok.gov.tr/UlusalTezMerkezi/
```

### Turkish Book
```
Çağdaş, A., & Erbil, D. (2019). Yönetim bilimi temel kavramlar [Management science: Basic concepts] (4. baskı). Eğitim Yayınları.
```

### Turkish Institutional Author
```
Afet ve Acil Durum Yönetimi Başkanlığı [Disaster and Emergency Management Authority]. (2023). 2023 yıl deprem raporu [2023 earthquake report]. AFAD Publications.
```

### Note on Titles
- In APA 7, capitalize the first word, proper nouns, and the first word after a colon in English titles.
- For Turkish titles in square brackets, maintain Turkish capitalization norms (only proper nouns capitalized).
