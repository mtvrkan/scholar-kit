# Harvard Citation Style

Harvard is a flexible author-date system widely used in business, social sciences, and diverse academic disciplines. It emphasizes author and year prominence.

## In-Text Citations

| Context | Format | Example |
|---------|--------|---------|
| Parenthetical, single | (Author Year) | Smith (2023) found that… |
| Parenthetical, no author | (2023) | Some evidence (2023) suggests… |
| With page number | (Author Year, p. 45) | A key finding (Smith 2023, p. 45) is… |
| Multiple pages | (Author Year, pp. 45–47) | The study (Smith 2023, pp. 45–47) noted… |
| Multiple authors (2) | (Smith & Jones 2023) | Smith and Jones (2023) note… |
| Multiple authors (3+) | (Smith et al. 2023) | Smith et al. (2023) report… |
| Multiple sources | (Smith 2023; Jones 2022) | Evidence (Smith 2023; Jones 2022) shows… |
| Same author, same year | (Smith 2023a, 2023b) | Two works (Smith 2023a, 2023b) conflict… |
| Corporate author | (National Institute 2023) | A report (U.S. National Institute of Health 2023)… |
| No author, no date | (Anonymous n.d.) | A study (Anonymous n.d.) found… |

## References List Format (20+ Source Types)

### Journal Article (with DOI)
```
Smith, J. and Jones, K. (2023) 'Title of article in title case', Journal Title in Title Case, 45(2), pp. 234–251. doi: 10.1234/example.
```

### Journal Article (online, no DOI)
```
Brown, L. (2022) 'Article title in title case', Research Quarterly, 18(3), pp. 445–462. Available at: www.example.com/article-url (Accessed: 15 January 2024).
```

### Journal Article (print)
```
Davis, R.M. and Wilson, H. (2021) 'Examining the phenomenon', Research Quarterly, 52(1), pp. 78–92.
```

### Book
```
Smith, K.A. (2020) Title of the Book in Title Case. 3rd edn. Publisher Name. doi: 10.1234/book.
```

### Book Chapter
```
Jones, M.R. (2019) 'Chapter title in title case', in Davis, L. (ed.) Edited Book Title in Title Case. Academic Press, pp. 45–67.
```

### Edited Book (emphasis on editors)
```
Davis, L. (ed.) (2019) Edited Book Title in Title Case. Academic Press.
```

### Conference Proceeding
```
Williams, P.J. (2023) 'Paper title in title case', in Proceedings of the 2023 International Conference on Computing, 15–17 June 2023, City, Country. Publisher, pp. 234–241. doi: 10.1234/conf.
```

### Doctoral Dissertation
```
Johnson, R.A. (2022) 'Title of Dissertation in Title Case'. PhD thesis, University Name.
```

### Master's Thesis
```
Lee, S. (2021) 'Title of Thesis in Title Case'. Master's thesis, University Name.
```

### Dataset
```
National Center for Biotechnology Information (2023) Gene Database: Release 233.0 [Data set]. Zenodo. doi: 10.5281/zenodo.example.
```

### Software
```
TensorFlow Developers (2023) TensorFlow: An Open-Source Machine Learning Library. Version 2.12.0. Available at: www.tensorflow.org (Accessed: 15 January 2024).
```

### Preprint (arXiv)
```
Taylor, N. and Kumar, A. (2023) Attention Mechanisms Revisited. arXiv:2301.12345. Available at: https://arxiv.org/abs/2301.12345 (Accessed: 15 January 2024).
```

### Webpage
```
World Health Organization (2023) COVID-19 guidelines. Available at: www.who.int/emergencies/diseases/novel-coronavirus-2019/ (Accessed: 15 January 2024).
```

### Report (Government/Organization)
```
U.S. Department of Education (2023) National Education Trends Report. Government Publishing Office.
```

### Technical Standard
```
International Organization for Standardization (2020) ISO/IEC 27001:2022 Information Security Management Systems. 5th edn. ISO.
```

### Translated Work
```
Kühn, T.S. (2020) The Structure of Scientific Revolutions. Translated by K. Fidan. 3rd edn. Alpha Publishing House. [Original work published 1962.]
```

### Institutional Author
```
Turkish Statistical Institute (2023) National Income Report 2022. TÜİK Publications.
```

### Newspaper Article
```
Reporter, P. (2023) 'Breaking news headline', The New York Times, 15 March, p. A1.
```

### Work Without Author or Year
```
Turkish Academy of Sciences (n.d.) Turkish Language Terminology Guide. Available at: https://tdk.gov.tr/ (Accessed: 15 January 2024).
```

### Multiple Authors
```
# One author
Smith, J. (2023)…

# Two authors
Smith, J. and Jones, K. (2023)…

# Three or more authors (all listed)
Smith, J., Jones, K., Brown, L., Davis, R., Wilson, H. and Taylor, N. (2023)…
```

### Same Author, Multiple Works (same year)
```
Smith, J. (2023a) 'First article', Journal A, 10(1), pp. 1–10.
Smith, J. (2023b) 'Second article', Journal B, 10(2), pp. 20–30.
```

## Key Formatting Rules

1. **Author-date emphasis:** (Author Year) appears prominently in both in-text and reference list.

2. **Title formatting in references:**
   - Article/chapter titles: 'Title in Single Quotation Marks with sentence case'
   - Journal/book titles: *Title in Title Case and Italics*

3. **Editor notation:** (ed.) for single editor, (eds.) for multiple editors

4. **Edition notation:** 2nd edn., 3rd edn., etc. (not "2nd ed.")

5. **Page notation:** p. (single), pp. (multiple), use en-dash: 45–51

6. **Date format:** 15 January 2024 or January 2024

7. **DOI format:** doi: 10.1234/example (or as a hyperlink in digital versions)

8. **URLs:** Include full URL; note access date in parentheses: Available at: URL (Accessed: date)

9. **Corporate/institutional authors:** Spell out full name at first reference; use standard abbreviation thereafter if very long.

10. **n.d.:** Use for "no date" works (n.d. not undated)

## Common Pitfalls

| Mistake | Fix |
|---------|-----|
| Inconsistent in-text vs reference formatting | Ensure author and year match in both places. |
| Missing DOI on recent articles | Check Crossref or journal website. |
| Wrong apostrophe style | Use straight apostrophes ('not ') for title quotes in references. |
| Incorrect page range separators | Use en-dash (–) not hyphen (-) or em-dash (—): pp. 45–51. |
| Turkish characters lost | Preserve UTF-8; never romanize ç, ğ, ı, ö, ş, ü. |
| Omitted "Available at" for online sources | Every URL must include "Available at: URL (Accessed: date)". |
| Mixed a/b notation inconsistency | If using (Smith 2023a, 2023b), ensure references show "Smith (2023a)" and "Smith (2023b)" separately. |
