# MLA 9th Edition — Citation Styles

## In-Text Citations

| Context | Format | Example |
|---------|--------|---------|
| Author-page (parenthetical) | (Author Page) | Smith finds that (45) or Smith finds that (Smith 45) |
| Author only, no page | (Author) | Some evidence (Smith) supports this |
| Quote with page | (Author Page) | A key quote: "The data shows…" (Smith 45). |
| Multiple sources | (Author1 Page; Author2 Page) | Evidence from two studies (Smith 45; Jones 30) suggests… |
| Multiple authors | (Smith and Jones 45) or (Smith et al. 45) | Smith and Jones note that (45) or (Smith and Jones 45) |
| No author, organization/website | (Organization) or short title | A report (American Psychological Association) states… |
| Multiple pages | (Author 45–47) | The study notes (Smith 45–47) that… |
| Entire work (no page) | (Author) | Smith's research (Smith) shows… |
| Personal communication | (Author Message) | According to personal correspondence (J. Smith, email) |

## Works Cited Format (20+ Source Types)

### Journal Article (online, DOI)
```
Smith, John, and Karen Jones. "Title of Article in Title Case." Journal Title in Title Case, vol. 45, no. 2, 2023, pp. 234–251, https://doi.org/10.1234/example.
```

### Journal Article (online, URL)
```
Brown, Lisa. "Article Title in Title Case." Research Quarterly, vol. 18, no. 3, 2022, pp. 445–462, www.example.com/article-url.
```

### Journal Article (print)
```
Davis, Robert M., and Helen Wilson. "Examining the Phenomenon." Research Quarterly, vol. 52, no. 1, 2021, pp. 78–92.
```

### Book
```
Smith, Kevin A. Title of the Book in Title Case. 3rd ed., Publisher Name, 2020, https://doi.org/10.1234/book.
```

### Book Chapter
```
Jones, Michael R. "Chapter Title in Title Case." Edited Book Title in Title Case, edited by Linda Davis, Academic Press, 2019, pp. 45–67.
```

### Conference Proceeding
```
Williams, Paul J. "Paper Title in Title Case." Proceedings of the 2023 International Conference on Computing, edited by Various Editors, IEEE, 2023, pp. 234–241, https://doi.org/10.1234/conf.
```

### Doctoral Dissertation
```
Johnson, Robert A. "Title of Dissertation in Title Case." Doctoral Dissertation, University Name, 2022. ProQuest Dissertations and Theses, www.proquest.com/.
```

### Master's Thesis
```
Lee, Sarah. "Title of the Thesis in Title Case." Master's Thesis, University Name, 2021. University Repository, repository.example.edu/.
```

### Dataset
```
National Center for Biotechnology Information. "Gene Database: Release 233.0." Zenodo, June 2023, https://doi.org/10.5281/zenodo.example.
```

### Software
```
TensorFlow Developers. "TensorFlow: An Open-Source Machine Learning Library." Version 2.12.0, Google, 2023, www.tensorflow.org.
```

### Preprint (arXiv)
```
Taylor, Nicholas, and Arun Kumar. "Attention Mechanisms Revisited." arXiv, 2023, https://arxiv.org/abs/2301.12345.
```

### Webpage
```
World Health Organization. "COVID-19 Guidelines." WHO, accessed 15 January 2024, www.who.int/emergencies/diseases/novel-coronavirus-2019/.
```

### Newspaper Article
```
Reporter, Public. "Breaking News Headline." The New York Times, 15 March 2023, p. A1.
```

### Report
```
U.S. Department of Education. "National Education Trends Report." Government Publishing Office, 2023.
```

### Standard/Technical Document
```
International Organization for Standardization. "ISO/IEC 27001:2022 Information Security Management Systems." 5th ed., ISO, 2020.
```

### Translated Work
```
Kühn, Thomas S. The Structure of Scientific Revolutions. Translated by Kübra Fidan, 3rd ed., Alpha Publishing House, 2020. Original work published 1962.
```

### Institutional Author
```
Turkish Academy of Sciences. "Turkish Language Terminology Guide." TDK, https://tdk.gov.tr/.
```

### Work Without Author or Date
```
"Turkish Language Terminology Guide." Turkish Academy of Sciences, https://tdk.gov.tr/.
```

### Multiple Authors
```
# Two authors
Smith, John, and Karen Jones.…

# Three or more authors
Smith, John, et al.…
```

### Same Author, Multiple Works (same year)
```
Smith, John. "First Article." Journal A, 2023.
Smith, John. "Second Article." Journal B, 2023.
```
In-text: (Smith, "First Article") or (Smith, "Second Article").

### Secondary Source (citing a source within another)
```
Aristotle (cited in Jones 45) argued that…
```
Works Cited includes only the secondary source (Jones).

## Turkish-Specific Examples

### Turkish Journal Article
```
Kaya, Mehmet, and Gülden Şimşek. "Görüntü Sınıflandırmada Derin Evrişimsel Ağların Performansı." Mühendislik Bilimleri ve Tasarım Dergisi, vol. 11, no. 2, 2023, pp. 245–258, https://doi.org/10.21923/jesd.example.
```

### Turkish Thesis
```
Özdemir, Ayşe. "Derin Öğrenme Kullanarak Türkçe Metin Sınıflandırması." Master's Thesis, Boğaziçi University, 2021. YÖK National Thesis Center, https://tez.yok.gov.tr/UlusalTezMerkezi/.
```

### Turkish Book
```
Çağdaş, Ayla, and Deniz Erbil. "Yönetim Bilimi Temel Kavramlar." 4th ed., Eğitim Yayınları, 2019.
```

### Turkish Institutional Author
```
Afet ve Acil Durum Yönetimi Başkanlığı. "2023 Yıl Deprem Raporu." AFAD Publications, 2023.
```

### Note on Turkish Titles
- MLA capitalizes the first word, first word after a colon, and all major words.
- For Turkish titles in quotation marks, apply Turkish capitalization (typically only proper nouns): "Türkçe metin sınıflandırması" (not "Türkçe Metin Sınıflandırması").
