# Chicago Manual of Style 17th Edition — Citation Styles

Chicago offers two systems: **Notes-Bibliography** (footnotes/endnotes + bibliography; humanities) and **Author-Date** (parenthetical in-text + reference list; sciences/social sciences). Both are supported.

## Author-Date System (In-Text)

| Context | Format | Example |
|---------|--------|---------|
| Parenthetical, single | (Author Year) | Smith (2023) found that… |
| Parenthetical, no page | (Author Year) | A study (Smith 2023) shows… |
| With page | (Author Year, 45) | A finding (Smith 2023, 45) is… |
| Multiple authors (2) | (Smith and Jones 2023) | Smith and Jones (2023) note… |
| Multiple authors (3+) | (Smith et al. 2023) | Smith et al. (2023) report… |
| Multiple sources | (Smith 2023; Jones 2022) | Evidence (Smith 2023; Jones 2022) suggests… |
| Same author, different years | (Smith 2020, 2023) | Multiple studies (Smith 2020, 2023)… |
| Same author, same year | (Smith 2023a, 2023b) | Two articles (Smith 2023a, 2023b) conflict… |
| Organization as author | (World Health Organization 2023) | A report (World Health Organization 2023)… |

## Notes-Bibliography System (Humanities)

### First Note (Full Citation)
```
1. John Smith and Karen Jones, "Title of Article in Title Case," Journal Title in Title Case 45, no. 2 (2023): 234–251, https://doi.org/10.1234/example.
```

### Subsequent Note (Short Form)
```
5. Smith and Jones, "Title of Article," 245.
```

### Bibliography Entry
```
Smith, John, and Karen Jones. "Title of Article in Title Case." Journal Title in Title Case 45, no. 2 (2023): 234–251. https://doi.org/10.1234/example.
```

### Full Examples (Notes-Bibliography)

**Journal Article:**
```
1. Lisa Brown, "Article Title in Title Case," Research Quarterly 18, no. 3 (2022): 445–462, www.example.com/article-url.
2. Brown, "Article Title," 450.
```

**Book:**
```
3. Kevin A. Smith, Title of the Book in Title Case, 3rd ed. (Publisher Name, 2020), https://doi.org/10.1234/book.
4. Smith, Title of Book, 78.
```

**Book Chapter:**
```
5. Michael R. Jones, "Chapter Title in Title Case," in Edited Book Title in Title Case, ed. Linda Davis (Academic Press, 2019), 45–67.
6. Jones, "Chapter Title," 52.
```

## Key Differences: Author-Date vs Notes-Bibliography

| Feature | Author-Date | Notes-Bibliography |
|---------|-------------|--------------------|
| Primary use | Sciences, social sciences | Humanities, history |
| Citation location | Parenthetical in-text | Footnotes/endnotes |
| Bibliography | Yes, required | Yes, required |
| Format | (Author Year, page) | Superscript number, then note |
| Title capitalization | Sentence case in most entries | Title Case or Sentence case (varies) |

For this kit: **Author-Date is recommended for most academic papers** (engineering, ML, data science). Notes-Bibliography is more common in history and literature.
