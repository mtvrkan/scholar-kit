# SRQR: Qualitative Research (Broader: Ethnography, Observation, Mixed)

## Checklist (21 Items)

| # | Item | Location |
|----|------|----------|
| **1** | Research question: stated explicitly and focused | Introduction (end) or Methods |
| **2** | Research design: named (phenomenology, grounded theory, ethnography, narrative inquiry, etc.) | Methods: Study Design |
| **3** | Research paradigm / theoretical framework: worldview, assumptions, lens | Introduction or Methods |
| **4** | Qualitative research tradition / discipline context | Introduction or Methods |
| **5** | Research setting: geographic, social, temporal context | Methods: Setting |
| **6** | Sampling strategy: purposive, maximum variation, convenience, snowball, etc.; rationale | Methods: Sampling |
| **7** | Participant characteristics: description of sample (N, demographics, relevant characteristics) | Methods or Results |
| **8** | Recruitment and enrollment: process, inclusion/exclusion criteria | Methods: Recruitment |
| **9** | Researcher–participant relationship: prior contact, self-disclosure, power dynamics | Methods: Reflexivity |
| **10** | Data collection methods: interviews, observation, documents, focus groups, etc. | Methods: Data Collection |
| **11** | Data collection procedures: how conducted, duration, timing, modifications (if any) | Methods: Data Collection |
| **12** | Data management: recorded, transcribed, stored, security; de-identification if applicable | Methods: Data Management |
| **13** | Reflexivity: researcher's background, biases, assumptions; efforts to minimize bias; data collection influence on findings | Methods: Reflexivity |
| **14** | Data analysis approach: described (thematic, content, constant comparison, etc.) | Methods: Data Analysis |
| **15** | Analytic process: coding, theme development, consensus processes, software used | Methods: Data Analysis |
| **16** | Software use: if used, did analysis depend on software algorithms or was software mainly organizational? | Methods: Data Analysis |
| **17** | Trustworthiness strategies: credibility, dependability, confirmability, transferability checks (member checking, peer debriefing, triangulation, etc.) | Methods: Quality Assurance |
| **18** | Reporting of findings: direct quotes with identifiers, theme-to-data connection, negative cases | Results |
| **19** | Interpretation: findings in context of literature, theories, assumptions; limitations acknowledged | Discussion |
| **20** | Conclusions: implications for theory, practice, research; generalizability qualified | Discussion / Conclusion |
| **21** | Funding sources and conflicts of interest; ethics approval | Funding statement & Methods |

---

## Key Differences from COREQ

| Focus | COREQ | SRQR |
|---|---|---|
| **Scope** | Interviews and focus groups only | Interviews, observation, ethnography, mixed methods, document analysis |
| **Items** | 32 items (detailed) | 21 items (broader) |
| **Use when** | Your study is purely interviews or FGs | Your study includes observation, ethnography, or mixed qualitative methods |

---

## Trustworthiness Strategies (Item 17 — Critical)

| Strategy | What It Is | Evidence to Report |
|---|---|---|
| **Credibility** (truth value) | Member checking, prolonged engagement, triangulation | "3 participants member-checked findings; all confirmed themes were accurate" |
| **Dependability** (consistency) | Audit trail, codebook documentation | "Complete audit trail available upon request; codebook development documented" |
| **Confirmability** (neutrality) | Bracketing, reflexivity, seeking disconfirming evidence | "Researchers bracketed assumptions by explicitly discussing preconceptions; actively sought disconfirming evidence" |
| **Transferability** (applicability) | Thick description of context and sample | "Detailed description of [setting/population] provided; readers can assess applicability" |

---

## Reflexivity Statement (Item 13 — Critical)

**Must include:**
1. **Who are the researchers?** Background, credentials, expertise, relationship to topic.
2. **What are their assumptions?** What did they believe before starting?
3. **What are their potential biases?** How might their identity/experience influence interpretation?
4. **How did they manage bias?** What processes, checks, or discussions happened?

**Example:**
> "The research team comprised A (RN with 12 years clinical experience in [setting], potentially biased toward medical model) and B (sociologist new to this setting, bringing critical perspective). We discussed our assumptions weekly during analysis to triangulate interpretations. When we found data challenging our initial beliefs (e.g., [specific example]), we actively explored why and revised our understanding."

---

## Thick Description (Item 18)

**Thick description** = detailed context + illustrative quotes, not just summary.

| Thin | Thick |
|---|---|
| "Patients felt frustrated." (summary only) | "Patients described frustration about lack of input. For example: 'Nobody asked what I wanted' (P07, setting: ICU, family member). Another: 'They decided for me without asking' (P12, setting: neurology ward, patient)." (context + quotes + sources) |
| "Staff implemented the new system poorly." (vague) | "In Ward A, staff printed the checklist but continued old workflow (P03, P05). In Ward B, staff integrated checklist into rounds, modifying timing (P08). These differences seemed related to leadership buy-in (charge nurse present vs. absent during rollout)." (context-rich description) |

## Common Omissions

| Item | Missing? | Fix |
|---|---|---|
| Research paradigm | Not stated (positivist? constructivist? critical?) | Add: "This study used a constructivist paradigm, recognizing that reality is co-constructed through researcher-participant interaction" |
| Reflexivity | No mention of researchers' backgrounds/biases | Describe: each team member's credentials, expertise, potential biases, and how they discussed assumptions |
| Trustworthiness | No mention of rigor strategies | Specify: "Member checking was conducted with 5 participants, all of whom confirmed the themes." |
| Negative cases | Disconfirming evidence ignored | State: "Most participants believed X; however, 2 participants disagreed because they believed Y (we explored why…)" |
| Thick description | Findings summarized, no quotes or context | Add: direct quotes (with participant ID + context), description of settings/situations |
| Audit trail | Analysis process opaque | State: "Detailed audit trail documenting coding decisions, theme development, and consensus discussions available upon request" |

## When to Use SRQR vs. COREQ

| Study Characteristic | Use COREQ | Use SRQR |
|---|---|---|
| Interviews or FGs only | ✓ | — |
| Interviews + observation or ethnography | — | ✓ |
| Document analysis + interviews | — | ✓ |
| Grounded theory (often uses observation) | — | ✓ |
| Phenomenology (usually interviews) | ✓ | (Either OK) |
| Mixed methods (qual component) | — | ✓ |
| Simple interview study | ✓ | (Either OK) |
