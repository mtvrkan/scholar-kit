# IEEE Citation Style — Citation Formats

IEEE is used in engineering, computer science, and technical fields. Citations are **numbered sequentially** [1], [2], etc., appearing in order of first mention in the text.

## In-Text Citations

| Context | Format | Example |
|---------|--------|---------|
| First mention | [1] | Smith found that [1]… or The research [1] shows… |
| Multiple consecutive | [1]–[3] | Multiple studies [1]–[3] demonstrate… |
| Multiple non-consecutive | [1], [3], [5] | Evidence [1], [3], [5] supports… |
| Citation with page | [1, p. 45] | A key finding [1, p. 45] is… |
| Multiple pages | [1, pp. 45–47] | The study [1, pp. 45–47] noted… |

Numbers are assigned in order of appearance in the text: first cited reference = [1], next new reference = [2], etc. Subsequent citations to the same reference reuse the same number.

## Reference List Format (20+ Source Types)

### Journal Article (with DOI)
```
[1] J. Smith and K. Jones, "Title of article in title case," Journal Title, vol. 45, no. 2, pp. 234–251, 2023, doi: 10.1234/example.
```

### Journal Article (online, no DOI)
```
[2] L. Brown, "Article title in title case," Research Quarterly, vol. 18, no. 3, pp. 445–462, 2022, [Online]. Available: www.example.com/article-url.
```

### Journal Article (print)
```
[3] R. M. Davis and H. Wilson, "Examining the phenomenon," Research Quarterly, vol. 52, no. 1, pp. 78–92, 2021.
```

### Book
```
[4] K. A. Smith, Title of the Book in Title Case, 3rd ed. Publisher Name, 2020. [Online]. Available: https://doi.org/10.1234/book.
```

### Book Chapter
```
[5] M. R. Jones, "Chapter title in title case," in Edited Book Title in Title Case, L. Davis, Ed. Academic Press, 2019, pp. 45–67.
```

### Conference Proceeding (with DOI)
```
[6] P. J. Williams, "Paper title in title case," in Proc. 2023 Int. Conf. Comput., June 2023, pp. 234–241, doi: 10.1234/conf.
```

### Conference Proceeding (online)
```
[7] R. Lee, "Conference paper title," in Proceedings of the 2023 IEEE International Symposium on Networks, May 2023. [Online]. Available: https://ieeexplore.ieee.org/...
```

### Doctoral Dissertation
```
[8] R. A. Johnson, "Title of dissertation in title case," Ph.D. dissertation, University Name, 2022, [Online]. Available: ProQuest Dissertations and Theses.
```

### Master's Thesis
```
[9] S. Lee, "Title of the thesis in title case," M.S. thesis, University Name, 2021.
```

### Dataset
```
[10] National Center for Biotechnology Information, "Gene database: Release 233.0," Zenodo, Jun. 2023, doi: 10.5281/zenodo.example.
```

### Software/Code
```
[11] TensorFlow Developers, "TensorFlow: An open-source machine learning library," Accessed: Jan. 15, 2024. [Online]. Available: www.tensorflow.org.
```

### Preprint (arXiv)
```
[12] N. Taylor and A. Kumar, "Attention mechanisms revisited," arXiv:2301.12345 [cs.LG], 2023.
```

### Webpage
```
[13] World Health Organization, "COVID-19 guidelines," Accessed: Jan. 15, 2024. [Online]. Available: www.who.int/emergencies/diseases/novel-coronavirus-2019/.
```

### Technical Report
```
[14] U.S. Department of Education, "National education trends report," Government Publishing Office, 2023.
```

### Standard/Technical Document
```
[15] International Organization for Standardization, "ISO/IEC 27001:2022 information security management systems," 5th ed., 2020.
```

### Translated Work
```
[16] T. S. Kühn, The Structure of Scientific Revolutions, K. Fidan, Trans., 3rd ed. Alpha Publishing House, 2020. [Online]. Available: https://example.com/. [Accessed: Jan. 15, 2024].
```

### Institutional/Government Document
```
[17] Turkish Statistical Institute, "National income report 2022," TÜİK Publications, 2023.
```

### Newspaper Article
```
[18] P. Reporter, "Breaking news headline," The New York Times, Mar. 15, 2023, p. A1.
```

### Work with No Individual Author
```
[19] Turkish Academy of Sciences, "Turkish language terminology guide," Accessed: Jan. 15, 2024. [Online]. Available: https://tdk.gov.tr/.
```

### Multiple Authors
```
# Two authors
[1] J. Smith and K. Jones,…

# Three to six authors (list all)
[1] J. Smith, K. Jones, L. Brown, R. Davis, H. Wilson, and N. Taylor,…

# Seven or more authors (list first six, et al.)
[1] J. Smith, K. Jones, L. Brown, R. Davis, H. Wilson, N. Taylor, et al.,…
```

### Same Author, Multiple Years
```
[1] J. Smith, "First article," Journal A, vol. 10, pp. 1–10, 2020.
[2] J. Smith, "Second article," Journal B, vol. 10, pp. 20–30, 2023.
```

## Key Rules

1. **Sequential numbering:** Each citation is numbered [1], [2], [3], … in order of first appearance.
2. **Author abbreviation:** Use initials only, e.g., J. Smith (not John Smith).
3. **Title case for most entries:** Journal articles and chapters use "Title Case in Brackets" or "sentence case in quotation marks," depending on type.
4. **Issue number:** Include if available, abbreviated as "no." for journals.
5. **DOI preferred:** If a DOI exists, include it at the end; otherwise, add [Online]. Available: URL.
6. **Months abbreviated:** Jan., Feb., Mar., Apr., May, June, July, Aug., Sept., Oct., Nov., Dec.
7. **Page ranges:** Use pp. for multiple pages; p. for a single page.

## Common Pitfalls

| Mistake | Fix |
|---------|-----|
| Out-of-order citations | Re-number references to match text order. |
| Inconsistent author abbreviation | Use initials for all authors: "J. Smith" not "John Smith". |
| Missing DOI on recent articles | Always check Crossref for a DOI; include if available. |
| Incomplete page ranges | For book chapters, include full range; for journals, if only page count is known, use "pp. 234–251". |
| Turkish characters lost | Ensure UTF-8 encoding in references; never romanize names. |
| Missing URL or DOI for online sources | Every online-only source needs either a DOI or full URL. |
